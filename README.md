# Prácticas Android Studio

Repositorio público con dos prácticas desarrolladas con Android Studio y Jetpack Compose.

- `happyBirthday/`: Práctica 1, pantalla de felicitación de cumpleaños.
- `MyApplication/`: Práctica 2, interfaz con Material 3, Scaffold, listas y Snackbar.

Cada carpeta es un proyecto Android independiente. Para abrir una práctica, selecciona su carpeta en Android Studio y sincroniza Gradle.
